A one-page newspaper front page summing up the world's news of Wednesday 18 November 2026: the Gulf strikes, the Kerch Bridge hit, Xi and Putin in Shenzhen, Peltola's Alaska win — plus Ebola, Voyager 1 and measles in the ticker. Four photo panels were generated for the day's stories and the front page was composed with headlines drawn crisply on top, so the date and every story stay legible.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, under 1 MiB). The program is standard-library only, uses no network, and writes the same bytes on every run.
